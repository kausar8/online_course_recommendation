# 🎓 Online Course Recommendation System

## 📌 Introduction

In today’s digital era, learners face difficulty in selecting the right course due to the availability of a large number of online courses. This project aims to solve this problem by building a **personalized course recommendation system** using data science techniques.

---

## ❗ Problem Statement

Learners struggle to find relevant courses due to **information overload** and lack of personalized guidance.

---

## 🎯 Objective

To develop a system that provides **personalized course recommendations** based on user preferences and behavior.

---

## 💡 Approach

* User-Based Collaborative Filtering
* Similarity Measurement using Cosine Similarity
* Interactive Web App using Streamlit

---

## 📊 Dataset Overview

The dataset includes:

* User ID, Course ID
* Course Name, Instructor
* Course Duration, Price
* Difficulty Level, Ratings
* Enrollment Numbers, Feedback Score
* Study Material Availability
* Time Spent & Previous Courses

---

## 🧹 Data Preprocessing

* Handled missing values
* Converted categorical data into numerical form
* Normalized features for better performance
* Selected relevant columns for recommendation

---

## 🤖 Recommendation Method

This system uses **User-Based Collaborative Filtering**, where:

* Similar users are identified based on their activity
* Courses liked by similar users are recommended

---

## ⚙️ Model Optimization

* Applied Cosine Similarity
* Filtered noisy and irrelevant data
* Improved recommendation accuracy

---

## 💻 Streamlit App Features

* User-friendly interface
* Input user details
* Displays top recommended courses
* Real-time recommendations

---

## 📈 Results

* Generated personalized course recommendations
* Improved user experience
* Reduced time spent searching for courses

---

## ✅ Advantages

* Personalized learning experience
* Time-saving
* Scalable system
* Easy-to-use interface

---

## ⚠️ Challenges
